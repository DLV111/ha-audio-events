Graphify Agent Refresh Instructions
==================================

Graphify index refresh for AI agents requires installation and proper setup:

1. Installation (once per agent):
   pip install graphifyy==0.9.64

2. Agent working directory should be the repo root

3. To refresh the index:
   graphify update .

4. Index location: graphify-out/graph.json

5. Version tracking: .graphify_version file

6. Dependencies: Python >= 3.12, pip available
